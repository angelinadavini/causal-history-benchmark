# Causal History Benchmark

This Space shows the public Causal History Benchmark results.

CHB asks: if a model has the same rule in front of it now, can the way it learned that rule earlier still change what it does next?

The code and reproducibility files are on [GitHub](https://github.com/angelinadavini/causal-history-benchmark).

# Research context

The benchmark sits at the intersection of mechanistic interpretability, in-context learning, memory, source provenance, and consciousness research.

## Nearest machine-learning work

The project is designed around several prior findings that already occupy nearby territory.

### Hidden-state persistence after source removal

MEMENTO shows that information from removed reasoning blocks can survive in later K/V state and affect later computation. This means generic K/V persistence is already established and is not a novelty claim here.

### Source provenance inside model representations

Recent work on computational reality monitoring and retrieved-context representations shows that parametric and retrieved information can leave different internal signatures. This means source history can be visible inside model state even when the final answer looks similar.

### Causal task representations

Function-vector and causal-abstraction work shows that task variables can be localized and manipulated through intervention. The benchmark uses this literature to justify causal tests rather than probe-only claims.

### Decodability and causal use

Mechanistic work has shown that information can be easy to decode while having little causal effect on the model's behavior. The benchmark therefore treats decodability and causal use as separate measurements.

## Human comparison

Human consciousness research already separates several stages that are often collapsed in AI discussions:

- early sensory or event-related processing;
- later access and integration;
- introspection;
- report;
- memory and later use.

No single property such as persistence, recurrence, integration, memory, flexibility, or self-report currently provides a theory-neutral test of consciousness.

The benchmark therefore does not ask whether one machine feature proves consciousness. It asks a narrower causal question about history:

> Does the route by which information entered leave a retained state that changes later processing after the original source is unavailable?

That result can then be compared with specific consciousness theories without treating any theory as settled ground truth.
